## What earns a point

The entry assigns one state to each tactical-video frame. H means Barcelona has possession with the ball alive, A means Athletic Club has possession with the ball alive, and D means a dead ball. X in the reference marks an ungraded frame. An entrant can emit X to abstain. The six sources establish these scored states. They do not specify an annotation convention for every disputed touch or pass in flight. A different nearest player on successive frames does not establish a change in team control. [Official task](https://github.com/metrica-sports/more-than-a-hack-2027/blob/f8f2629ff1e0985f81d7e59d8413678514ee1530/README.md) · [Metric definitions](https://github.com/metrica-sports/more-than-a-hack-2027/blob/f8f2629ff1e0985f81d7e59d8413678514ee1530/evaluation/possession_metrics.py)

The primary score, **spellF1**, measures the recovery of maximal uninterrupted H and A intervals. Each predicted interval may match one reference interval of the same team. At each temporal intersection-over-union threshold (0.3, 0.4, 0.5, 0.6, 0.7), the scorer greedily takes eligible pairs in descending overlap order. F1 at that threshold is twice the number of matches divided by the total number of predicted and reference spells when the denominator is positive. The board averages those five F1s. A short spell counts as one possession, just like a long spell. D runs are excluded as spells, but an inserted or missed stoppage can split or merge possessions. The first tie-break is the unweighted mean of H, A and D frame F1. Further ties use destination-labelled transition F1 at the looser tolerance (25 frames by default), then smaller mean absolute latency there, then entry name. [Metric definitions](https://github.com/metrica-sports/more-than-a-hack-2027/blob/f8f2629ff1e0985f81d7e59d8413678514ee1530/evaluation/possession_metrics.py) · [Ranking code](https://github.com/metrica-sports/more-than-a-hack-2027/blob/f8f2629ff1e0985f81d7e59d8413678514ee1530/evaluation/run_evaluation.py)

**Why a single frame can matter.** In a synthetic 101-frame H spell, predicting 50 H, one D, then 50 H gives 100/101 correct frames. The two predicted H intervals each have IoU 50/101. Only one can match, and only at 0.3 and 0.4. SpellF1 is consequently about 0.267. Smoothing away that false interruption would help. Smoothing away a genuine brief change of possession would instead erase a scored event. [Scoring algorithm](https://github.com/metrica-sports/more-than-a-hack-2027/blob/f8f2629ff1e0985f81d7e59d8413678514ee1530/evaluation/possession_metrics.py)

X on a graded frame costs a frame-level miss. For temporal scoring the scorer forward-fills predicted X within each graded run, backfills leading X from the first known state, and leaves wholly abstained runs X. Filling never crosses a reference X gap. The standalone validator counts possessions differently when the entry contains X because it lacks the reference mask. A plausible count in its summary establishes neither accuracy nor ranking. [Metric definitions](https://github.com/metrica-sports/more-than-a-hack-2027/blob/f8f2629ff1e0985f81d7e59d8413678514ee1530/evaluation/possession_metrics.py) · [Validator](https://github.com/metrica-sports/more-than-a-hack-2027/blob/f8f2629ff1e0985f81d7e59d8413678514ee1530/evaluation/validate_submission.py)

## Independent priorities before seeing any work

1. **Prove the contract on invented sequences.** Exercise the frame conversions, team mapping, half boundaries, X fill, one false stoppage, one missed restart and one brief genuine turnover. Run the official validator on an end-to-end generated CSV. Compare two clean regeneration runs byte for byte. These tests separate implementation defects from uncertainty in the football evidence.
2. **Establish an external evaluation that can discriminate between methods.** Seek accessible, licensed other games with time-aligned team-control and stoppage labels, ideally with automatic observations resembling the challenge. Verify label semantics for passes, turnovers, contests and restarts before trusting scores. Split by match. Report score and paired differences by game and show how many spells contributed. Perfect tracking or sparse event timestamps may support software checks while giving a misleading impression of performance under camera occlusions. If no representative external reference exists, record that uncertainty. Plausible duration or count cannot certify private spellF1.
3. **Build the cheapest informative comparison.** On the external data, compare ball-to-team proximity with an offline sequence method that uses evidence before and after ambiguous stretches, handles dead/alive explicitly, and can preserve a brief supported turnover. Test the separate incremental value of persistence, player motion during missing-ball stretches, and phase/restart evidence where matching tags exist. Record spell precision and recall at each IoU, class-specific frame F1, short versus long spell recovery, and boundary errors for dead→live, live→dead and team changes. A fall at strict IoU suggests boundary errors worth checking on external footage. A surplus of unmatched predictions warrants separating false splits from wrong-team calls.
4. **Spend on another modality only after identifying its job.** Consider a frozen local visual model or automatically aligned broadcast if external errors concentrate in a specific condition, such as reacquisition after occlusion. Require evidence of incremental recovery there, coverage, alignment quality and an explicit fallback. A more accurate detector can add substantial effort without fixing a wrong restart decision. Rebuilding identity tracking, matching aggregate possession share, choosing whichever smoother wins on the public five minutes, or policing a single expected number of possessions each directs effort away from the actual criterion.

These are proposed experiments and failure modes. Their value for this participant remains unknown until the separate work packet is assessed.
