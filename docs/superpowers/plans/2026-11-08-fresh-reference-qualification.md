# Fresh full-state reference qualification plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this bounded research work package. Checkboxes are future actions, not evidence of source qualification.

**Goal:** Resolve one concrete path to genuinely unused, lawfully accessible full H/A/D evaluation evidence, or document the external dependency precisely.

**Architecture:** Documentation-first review of at most three existing scout leads, followed by one selected source's rights/ontology/non-overlap and resource assessment. Freeze access boundaries and an evaluation or external-annotation protocol before model outcomes are examined. Do not acquire data, create annotations or score a model under this qualification plan.

**Tech Stack:** Existing Markdown/JSON documentation and primary-source browsing; no training or new dependencies.

**Spec:** `../specs/2026-11-08-post-audit-roadmap-design.md`, Workstream B. This project is independent of the cadence pilot. Execute as a separate goal after the active predecessor is achieved, even if its external access would later permit scientific work to proceed in parallel.

## Global constraints

- No challenge GT/video/target arrays, target tuning or new target outputs.
- Start with `docs/fresh-had-cohort-scout.md`, `docs/accuracy-first/accuracy-reference-update.md` and existing research audits; inspect at most three leads unless all fail and a new search is explicitly scoped.
- Read source documentation/licences/access terms, not candidate prediction outcomes. Browsing must verify current rights/access; old scout notes are leads, not current legal permission.
- No paid acquisition, account creation, messages to source owners or manual annotation execution in this task. Record those dependencies; ask only for a concrete missing decision after producing a reviewable source proposal.
- Do not rename used matches fresh. Match/team/time overlap, provider dependence and H/A/D semantic differences must be recorded.

## Review focus

1. A dataset licence may exclude labels, video or redistribution even when code is open — record each asset's rights separately.
2. Event possession or live-only phases do not supply dense D truth — document unknown support and reject fabricated stoppages.
3. Repeated teams/matches/providers can undermine the intended independence — preserve identity/use ledgers.
4. A small convenient clip may lack class/short-spell support — require a prospective support and power rationale.
5. Opening outcomes before selection invalidates an unopened qualification claim — freeze candidate, comparator and access roles first.

## Task 1: bounded source qualification record

**Read:** existing scout documents and linked primary sources.
**Create:** `docs/reference-qualification/source-comparison.md`, `source-qualification.json`.
**Produces:** one record per considered source with `source`, `documentation_checked_on`, `primary_links`, `asset_rights`, `access_steps`, `dense_HAD_status`, `ontology`, `known_overlap`, `label_independence`, `resource_estimate`, `unresolved_dependencies`, `disposition`.

- [ ] Read the existing scout conclusions and rank at most three leads before inspecting any model outcomes.
- [ ] Verify current primary documentation for rights, asset availability and label ontology. Record unknowns as unknown; a repository's permissive code licence is not blanket data permission.
- [ ] Check source identities against the existing fitting/development/validation/regression ledger without loading reference arrays. Separate previously visited documentation from previously scored data.
- [ ] Select one lead only if there is a credible legal/full-state/non-overlap path; otherwise explain why every considered lead fails. Validate that every positive factual assertion links to supporting primary evidence and every unresolved dependency names the needed action.

## Task 2: qualification or external-annotation protocol

**Create:** `docs/reference-qualification/evaluation-protocol.md`, `access-and-use-ledger.json`.
**Consumes:** Task 1's selected record or explicit all-fail disposition.

- [ ] If a source qualifies, specify allowable acquisition, storage/egress, original indexing/time/team roles, development/calibration/qualification partitions, reference-X semantics, class/event support and a match-level sample/power rationale before outcomes are opened.
- [ ] Freeze the chosen candidate/comparator and all-state metrics/decision rules. Preserve chronological access records; define what consumes a qualification set and what happens after failure. Do not select a baseline window on qualification outcomes.
- [ ] If dense labels must be created, specify independent blinded external labeling, an annotation manual, disagreement/adjudication and ambiguity-X policy; estimate cost and rights needs. This is a proposal, not permission to label or buy data now.
- [ ] If access/rights/full-state support cannot be resolved, deliver the concrete dependency and retain exploratory status. Do not mark scientific qualification achieved merely because this research task completed.

## Task 3: evidence and handoff check

- [ ] Check all five Review Focus risks against both records. Verify primary links and date-sensitive access statements; distinguish inference from source facts.
- [ ] Produce a short user-facing decision: selected source and next permitted step, or exact unresolved requirement. No generic recommendation to “get more data.”
- [ ] Finish this qualification-planning goal before creating another goal. Actual acquisition, annotation or locked evaluation receives a separate scoped plan and any genuinely necessary resource approval.

Self-review: this package is independently completable without model scoring; a documented inability to qualify a source is an honest deliverable. It cannot by itself establish fresh generalization.
