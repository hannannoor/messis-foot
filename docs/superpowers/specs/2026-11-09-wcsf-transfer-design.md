## Parsing, isolation and clocks

The geometry parser requires `x,y,group_id,timestamp_ms,x_ball,y_ball,player_id`; reference parsing additionally requires `AliveFlag,PossessionFlag`. Ignore documented speed, acceleration and team_game_phase and an optional export-index column; never pass them to inference. Accept UTF-8 BOM and exactly one unambiguous comma/semicolon/tab delimiter yielding unique required headers. Unknown extra columns are ignored, not inferred as metadata or features. Reject ambiguous/missing/duplicate headers and invalid timestamps, group IDs or player IDs. Parse finite coordinate numbers; empty/nonfinite coordinates mean unavailable. No source row or state value is printed on failure.

Stream to separate private SQLite geometry and reference databases. Geometry keys are unique `(period,timestamp_ms,group_id,player_id)`; identical geometry duplicates collapse and conflicting geometry duplicates fail structural qualification. Reference rows retain **every source row**, keyed by `(period,source_row_ordinal)`, including conflicting flags on otherwise identical geometry duplicates. Reference differences cannot veto geometry qualification or become first/last-row-wins truth. Anonymous player IDs must retain one team across both files. Source timestamps are integral, between 0 and 86,400,000 ms inclusive, and on a 100 ms lattice relative to each half's first timestamp; source row order need not be sorted. A half's last-minus-first span must be at most 5,400,000 ms (at most 135,001 canonical rows); reject larger spans before allocating a grid. Sort by timestamp/player ID in SQLite; period is the archive identity. Keep original timestamps, do not infer absolute kickoff/halftime identity from outcomes. Missing native samples remain missing; no guessed source frame is inserted as observed.

The raw CSV physically contains references. Record the first machine reference-access event at ingestion, even though reference values are quarantined and not shown. Freeze complete code, hypotheses, thresholds, methods, scorer and reference mapping **before ingestion**. Structural decisions consume geometry only. No reference support/statistics or predictions are inspected until the geometry contract has passed and its receipt is sealed. The source can then be described as outcome-unopened before scoring, not as never parsed. Perturbing all references must leave geometry, reconstruction choice, grids and predictions unchanged.

## Geometry qualification without outcomes

The guide states own goal negative X for both teams and ambiguously describes ball coordinates relative to each player. Test exactly four global interpretations, not per-frame cherry-picking:

1. Ball coordinates already absolute in that team's frame; away transform `(-x,y)`.
2. Same absolute interpretation; away transform `(-x,-y)`.
3. Ball is a player-relative offset, so add `(x,y)` first; away transform `(-x,y)`.
4. Same offset interpretation; away transform `(-x,-y)`.

Home is the common frame. Eligibility is identical for all four candidates: each team must have at least three distinct players with finite `(x,y)` and at least two distinct players whose player and ball pairs are both finite. Only rows with both finite pairs contribute reconstructed ball candidates, even for absolute-coordinate interpretations. Compare all those pairs after transformation. A candidate passes that frame when the maximum pairwise separation is at most **0.25 m**. Evaluate the complete native geometry cohort. Require at least **100** eligible timestamps and exactly one candidate with at least **99%** passing timestamps (integer check `100*passes >= 99*eligible`). If zero or multiple candidates pass, stop; do not choose by reference agreement, expected team, trajectory speed or model outcome. The deliberately conservative uniqueness requirement may reject an otherwise usable source; that is preferable to claiming a validated transform from ambiguous evidence. No semantic assumption about identity or fresh physical measurement is established by consensus.

Use the selected interpretation on all frames. For each native ball, require two distinct player rows per team with both finite pairs and the same 0.25 m diameter rule; reduce the agreeing reconstructed points to their coordinate-wise median (an even count uses the arithmetic mean of its two middle coordinates). Missing player coordinates cannot contribute a ball pair. Collapse identical geometry duplicates before this calculation. This per-frame ball rule does not require the third player used for global qualification. Failing/missing consensus means missing ball, never D. Player positions use the selected away reflection. Convert center-origin source metres to the existing predictor convention as `(x*105.3/105 + 52.65, y + 34)`. Player/ball coordinates outside the pitch remain legitimate out-of-bounds geometry; do not infer D from range clipping or supplied state. No raw geometric rows leave local storage.

## Canonical grid and references

For each half, use times `first_native_ms + 40*k <= last_native_ms`. Keep the original time/period mapping. At exact native times use valid source geometry. Between immediately adjacent timestamps exactly 100 ms apart, linearly interpolate only players present with valid coordinates at both endpoints and ball pairs valid at both endpoints. No extrapolation or interpolation across an absent/invalid native sample. Invalid/missing time slots have unusable geometry; reference values never determine this. Preserve anonymous player IDs and native/interpolated provenance, including both endpoint times in private storage and aggregate counts. Native means supplied preprocessed 10 Hz, not verified fresh sensor acquisition. Scale coordinates before MotionFrame construction; set `dead_evidence=False`, empty tags and no restart hints.

Reference consensus is separate: at one native timestamp, all player rows, including duplicates, must agree on AliveFlag; when alive they must agree on PossessionFlag. Valid dead 0 maps D, valid alive 1 plus owner 1/2 maps H/A; conflicting/missing/invalid reference becomes X. Possession disagreements on a valid dead frame do not override D. At **every exact native instant** represented on the canonical grid use that instant's consensus, including before a gap and at the final instant. Otherwise use the left native reference only when both adjacent native timestamps exist and are exactly 100 ms apart. Intermediate grid times across a gap are X. Do not extrapolate past the last source instant. No lag fitting, smoothing or interpolation of state boundaries. References are precision-limited to 100 ms; report 40 ms canonical sampling as a transform, not extra independent truth.

## Expected limits and implementation choices

Unresolved source semantics (contests/flight, manual errors, smoothing), one anonymous match and 10 Hz precision remain even after a technically passing adapter. Time-alignment accuracy cannot be proven by input consensus. The planner chooses SQLite streaming, four hypotheses, 0.25 m/99%/100-frame structural bounds, no-clobber private files and descriptive endpoints for a bounded, auditable implementation. These are engineering proposals, not user-approved or outcome-tuned values. The builder may choose internal dataclasses, transaction batching and diagnostic counter organization, while preserving these contracts.
