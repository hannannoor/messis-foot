Do not label it a ready dense benchmark until those checks pass; do not label one match an independent estimate of population accuracy.

No fitted model or parameter may be chosen after its outcomes are opened. Keep the current frozen control; exclude the rejected velocity-only contrast from automatic expansion. ## Fallback assessment

SoccerTrack's explicit data licence is a useful legal/documentary difference from an unlicensed code-only source. Its GSR schema describes player entities; BAS describes events, which cannot be carried into dense truth. The maintainers document released-format and half-time alignment inconsistencies and multi-GB annotation files. Creating independent state labels plus compatible ball observations would be a separate, materially larger project. Metadata access succeeded, while canonical HF reports `gated=auto`; no gate was accepted. [Data licence](https://github.com/AtomScott/SoccerTrack-v2/blob/a752d294df2a0e816e827b70f284980698f5a50e/LICENSE-DATA), [BAS specification](https://github.com/AtomScott/SoccerTrack-v2/blob/a752d294df2a0e816e827b70f284980698f5a50e/docs/format-bas.md), [canonical dataset metadata](https://huggingface.co/api/datasets/atomscott/soccertrack-v2).

PFF remains a potential future source, not a failed dataset. Its public announcement alone does not establish the needed dense reference or permission terms. No form, account, payment or message is needed to finish this bounded review; those actions were not taken.
