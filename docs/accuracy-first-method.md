# Accuracy-first experiment

The current agreement route fills uncertain labels while preserving every existing H/A/D label. A read-only audit of external development references found that some preserved labels are already wrong, mostly H/A swaps. The proposed experiment tests whether finite sequence evidence can correct them without creating more errors.

The user approved this bounded experiment on 7 November 2026. The complete [design](superpowers/specs/2026-11-07-accuracy-first-design.md) fixes16 settings, reference splits, selection and rejection rules before scoring. Existing frozen heads are reused without fitting. A new three-state Viterbi decoder combines raw tactical H/A/D leaf support and symmetric motion H/A scores, with finite state-switch costs. Earlier labels are not hard anchors. Inapplicable frames are decoder barriers with latent X; structural-period carry is reported separately.

The source/code/model/cache freeze is `reports/accuracy-first/comparison-freeze.json`. Selection uses only the named **previously examined validation** matches, with equal provider then match weighting; natural-input spellF1 is primary and macroF1 breaks ties. The30% ball-missing stress uses the unchanged input-only masking function and seed1729. It does not use target patterns or reference labels. After selection, one frozen comparison uses the old test matches as **seen regressions**, never as fresh holdouts. No settings are changed after that comparison.

The unchanged four comparators are incumbent, carry, agreement and agreement-plus-carry. Vectorized score preparation is checked against the portable heads and the exact original four-policy runtime on synthetic inputs. Besides spellF1 and frame/class metrics, reports count corrections to incorrect incumbent labels, regressions from correct labels, per-IoU matched/spurious/missed possession counts, and overlap-based split/merge diagnostics. The latter are descriptive overlaps, not mutually exclusive causal explanations. Unlabelled reference regions remain unknown and emitted H/A/D there are reported as unmeasured.

## Reference rights and semantics

- DFL/IDSSE: [provider dataset publication](https://doi.org/10.1038/s41597-025-04505-y), [CC BY4.0 release](https://doi.org/10.6084/m9.figshare.28196177.v1). Canonical25Hz player/ball geometry and provider BallStatus/BallPossession reference are co-timed. Those reference fields never enter inference. Inactive ball coordinates are almost always frozen in this provider: high D performance can reflect that shortcut and does not prove target stoppage accuracy.
- SkillCorner: [pinned MIT open-data release](https://github.com/SkillCorner/opendata/tree/4340d274572876239c154c90bc507a9b3250a656). Native10Hz detected observations are resampled to the canonical25Hz grid, including player-identity-assisted interpolation. Phase reference supports known-play H/A; absence of annotation is X, never independent D. Estimated anonymous correspondence is used consistently for all compared methods, but resampled coordinates limit how closely these data simulate anonymous ATD slots.

Both heads were fitted on external development matches rather than the named validation/regression matches, but all matches in this cycle have already appeared in previous project analyses. Therefore model selection and regression scores are exploratory. No independently fresh full H/A/D cohort has been verified; the acquisition/recon notes document rejected near-fits. No target GT, provided video, hand labels or challenge-driven tuning are part of model selection. After the external selection and seen-regression decision, separate target runs test execution, original-index CSV format and exact reproducibility only; their per-frame outputs remain local and their accuracy is unmeasured.

The current route is retained unless the predeclared selection and seen-regression primary comparisons both improve. A candidate that passes remains an opt-in experiment; this result cannot establish target correctness. A rejected candidate is recorded with its scores and failure modes, without modifying the existing CLI or searching another parameter grid after the result.

Source assets, intermediate scores and per-frame predictions stay local in `accuracy-reference/`. Only source code, documents and scalar/count aggregate reports are eligible for GitHub publication; raw transition matches/locations are excluded recursively.
