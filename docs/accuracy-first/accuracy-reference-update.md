# Independent accuracy reference update —7 November2026

Read-only documentation research for the new accuracy goal. No new data assets, reference files, video, weights or dependencies were downloaded, no accounts/forms used and no authors contacted. The original fresh-cohort scout remains valid; this note adds the sources below rather than repeating its search as new validation.

- **SkillCorner body-pose release:** provider [dataset card](https://huggingface.co/datasets/SkillCorner/opendata-bodypose) declares MIT and documents two matches,1925299/1996435. Both are in the20 already opened matches. XY is interpolated from10Hz tracking to25Hz; the new pose release is not a fresh football match or new dense H/A/D reference. No archives fetched.
- **SoccerTrack v2:** the authors' [dataset documentation](https://atomscott.github.io/SoccerTrack-v2/) specifies ten full amateur matches, per-frame player positions/team/identity and12 action-spotting labels; data CC BY4.0, code MIT. The documented GSR/BAS fields do not establish a dense team-possession plus alive/dead reference. Do not manufacture it by carrying event labels. This may support another task, but is not verified as the required full-state accuracy holdout.
- **DEBS2013:** the data custodians' [problem description](https://mlps-lab.de/datasets/debs-2013-grand-challenge-soccer-monitoring/) documents a7-a-side sensor match and a separate small file of manually created game-interruption, possession and shot statistics. This is a new lead, but the inspected documentation does not establish explicit applicable data/reference rights, dense ownership reference or11-a-side transfer. Those statistics may be aggregate rather than interval ownership; no file was fetched and no H/A/D benchmark was asserted. The published possession query is itself a sensor-contact rule; executing that rule is not independent ground truth.
- **Magglingen2013:** the original [Datahub record](https://api.old.datahub.io/en/dataset/magglingen2013) reports10Hz U19 recordings and CC-BY-SA. Its `curBPTeam` is under calculated/accumulated values, and team0 denotes error rather than dead ball. The inspected record does not establish independent possession annotation or dense alive/dead labels. No match assets acquired.
- **DataBallPy:** [pinned README](https://github.com/Alek050/databallpy/blob/4f500ef0ba522313fa6ec419707db7cd6e0c2624/README.md) points its current open-game API at the same seven DFL/IDSSE matches. More parsers and a package licence do not supply a new licensed full-state cohort. Only README/tree metadata inspected.
- **PFF:** the [provider release page](https://www.blog.fc.pff.com/blog/pff-fc-release-2022-world-cup-data) still directs access through a form. Rights/reference semantics remain unverified here; no form submitted.
- **Other possession research:** the authors' [player-only alive/dead study](https://pmc.ncbi.nlm.nih.gov/articles/PMC9522646/) says its data are not public and available on reasonable request. A reported result or a software licence does not grant dataset access. No contact made.

The official [competition rules](https://github.com/metrica-sports/more-than-a-hack-2027/blob/f8f2629ff1e0985f81d7e59d8413678514ee1530/RULES.md) reserve the public five minutes for pipeline correctness checks and explicitly exclude training/tuning; the participant-supplied clarification additionally excludes output/video comparison and challenge-driven fitting. This cycle keeps its already established no-target-GT/video-check protocol. It does not treat a public five-minute score as independent model-selection evidence.

Conclusion: no new qualified fresh full-state cohort verified. A bounded external development experiment remains possible using existing licensed data, but its scores must stay labelled exploratory/seen-data. Fresh reference acquisition and real target correctness remain unresolved.
